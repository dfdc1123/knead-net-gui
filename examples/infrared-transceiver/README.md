# Infrared transceiver / 红外发射接收模块

This directory contains a KiCad export of the open-source hardware project
[红外发射接收模块_2026-06-08_16-19-02](https://oshwhub.com/xindingsheng/project_xbshrerd)
by [芯鼎盛-硬件吴工 (`xindingsheng`)](https://oshwhub.com/xindingsheng).
The upstream project describes an infrared wireless communication module and
is published under the GPL 3.0 license.

The imported directory and KiCad project have been renamed to
`infrared-transceiver`. KiCad local-history data, nested Git metadata, lock
files, and local preference files are intentionally not included; the
schematic, PCB, project file, symbol library, and symbol-library table are
retained.

## KneadNet compatibility

The PCB footprints were converted from the upstream SMD defaults to THT
footprints on 2026-07-27. This version can be imported into KneadNet and is
also used to cover KiCad root-sheet local-label handling: the schematic label
`TX` corresponds to the canonical PCB net name `/TX`.

The footprint substitutions are examples, not manufacturing recommendations.
Before building the circuit, verify every selected package, pin number,
orientation, and physical part against its datasheet.

## Why KiCad shows `1111`

`1111` is not generated by KneadNet. It is the `Reference` of the imported
`Drawing-Symbol_A4` schematic symbol, which draws the decorative EasyEDA page
frame. The imported symbol has an empty reference prefix and is incorrectly
marked as a BOM/board item, so KiCad assigned it the numeric reference `1111`
and includes it in the footprint-assignment list. It has no electrical role
and no PCB footprint. If the drawing frame is not needed, it can be removed;
alternatively, exclude that symbol from the BOM and board.
